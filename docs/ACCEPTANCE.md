Все пункты пока имеют статус «не выполнено»: это план проверки, а не отчёт о готовом продукте. При выполнении добавить дату, среду и наблюдаемый результат. Данные только вымышленные.

## Уровни проверки

1. Unit: построение клавиатуры, валидация формы, кодирование callback и поисковых значений. Только логика с полезными граничными случаями.
2. Прямые интеграционные запросы: RLS, права и ограничения реальной тестовой БД с A/B/anon. Без service_role для доказательства пользовательской изоляции.
3. Браузер: основной жизненный цикл и двойное нажатие, мобильный экран; минимум два независимых контекста пользователей.
4. Живое демо: Telegram и опубликованное приложение, проверка ссылок и инструкции повторного запуска.

Успешные mock-тесты не заменяют уровни 2 и 4. Чеклист считается закрытым только при наблюдаемом результате в указанной среде.
