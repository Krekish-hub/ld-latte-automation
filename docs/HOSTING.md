# Предварительная проверка VPS

## Размещение, 30 октября

Инфраструктура запущена: статическая страница на ретрансляторе, n8n 2.45.6 на первом VPS, связь через отдельный SSH-туннель. HTTPS проверен извне. Подробности, границы выполненной проверки и откат: [deploy/README.md](../deploy/README.md). Приложение заявок и Telegram workflow пока не опубликованы.

На первом VPS при повторном входе обнаружены Ubuntu 24.04.5 и работающий Xray на 443/8443; это изменения вне данной настройки. Их конфигурация не изменялась. Поэтому первая инвентаризация ниже описывает состояние на свою дату, а не текущие порты.

## Дополнительный сервер ретрансляции, 30 октября

Проверен по SSH только на чтение, сессия закрыта. Адреса, домены маршрутизации и секреты здесь не сохраняются.

- Ubuntu 26.04 LTS, 1 vCPU, 985 MiB RAM; available около 676 MiB; swap нет.
- Диск 9.8 GiB, свободно около 5.3 GiB.
- Docker отсутствует. Работают HAProxy, Caddy, Xray, x-ui и служба ретрансляции.
- HAProxy занимает публичный TCP 443, маршрутизирует TLS по SNI: часть запросов в локальный Caddy, остальные на удалённые сервисы. Caddy занимает TCP 80 и локальные HTTPS-порты.
- Для размещения нельзя запускать второй proxy на 80/443. Новый сайт требует отдельного имени и точечного дополнения существующих HAProxy/Caddy с проверкой конфигураций и откатом.

Уточнение архитектуры: этот сервер рассматривается прежде всего для статического frontend и входного HTTPS-маршрута. Совместное размещение n8n при текущем запасе памяти без swap не принимается как основной вариант. Предварительно n8n остаётся на ранее проверенном сервере с 2 GiB либо на отдельном хосте. Окончательное распределение и имена ещё не выбраны. На обоих серверах в рамках проверок ничего не устанавливалось и не менялось.

## Первый сервер, 29 октября

Проверено 29 октября 2026 по SSH, только чтение. Учётные данные и адрес инфраструктуры в репозитории не сохраняются.

- Ubuntu 24.04.4 LTS, x86_64.
- 1 vCPU, 1.9 GiB RAM; доступно около 1.2 GiB на момент проверки.
- Swap 511 MiB, использовано около 103 MiB.
- Диск 30 GiB; свободно около 18 GiB.
- Работает Docker: Amnezia AWG, Beszel и агент; отдельно AdGuard Home.
- Плагин Docker Compose отсутствует; установка ещё не выполнялась.
- TCP 80/443 на момент проверки не слушаются. Возможные внешние ограничения сети ещё не проверены.
- Система сообщает о необходимых обновлениях и перезагрузке. В рамках проверки они не выполнялись.

Предварительно VPS пригоден для небольшого тестового размещения статического веб-приложения и n8n при контроле памяти. Supabase планируется облачный; разворачивать весь Supabase на этом VPS не планируется. Сборка приложения выполняется вне VPS. Перед размещением нужны HTTPS-имя, проверка маршрутизации и ограничений сети, отдельные volumes/сеть/лимиты для новых сервисов. Существующие VPN и DNS-сервисы не изменяются.
