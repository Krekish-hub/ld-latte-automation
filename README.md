# LD LATTE: тестовое по автоматизации

Репозиторий для трёх независимых результатов. Сейчас подготовлен план; реализация и проверка на внешних сервисах ещё не выполнены.

- `automation/`: экспорт n8n, тестовые услуги, инструкция и сценарии демонстрации Telegram-бота.
- `docs/instagram/`: исследование официальных API, схема, метрики, план подключения и проверки.
- `apps/web/`: приложение заявок с Supabase Auth и Postgres.
- `supabase/`: миграции, RLS и тестовые данные без реальных сотрудников.
- `docs/`: архитектура, критерии приёмки и журнал использования AI.

Получено 29 октября 2026 в 17:00 (Asia/Chita). Дедлайн: 31 октября 2026 в 17:00 (Asia/Chita).

Секреты хранятся в настройках сервисов или локальном `.env`, не в Git. Инструкции запуска появятся вместе с реализацией.
